# 编码铁律

## 通用编码铁律

> 描述通用编码规范，必须简洁明了，采用反模式方式描述

- **禁止**跨 IPC 边界直接调用另一进程对象，**采用** IPC Proxy/Stub + MessageParcel 序列化通信
- **禁止**为录屏单独引入引擎选择层或 Pipeline，**采用**直接调用 Rosen VirtualScreen + AudioCapturer + Recorder 引擎（通过依赖注入接口）
- **禁止**绕过能力位图状态机直接执行录屏操作，**采用** `IsState(cap)` 校验，非法状态返回 MSERR_INVALID_OPERATION；新增状态时同步扩展状态-能力映射数组
- **禁止**跳过权限校验或隐私授权流程直接开始录屏，**采用** StartScreenCapture 前校验 CAPTURE_SCREEN 权限 + 隐私授权（弹窗或 EXEMPT 权限）
- **禁止**虚拟屏幕创建后不配对销毁，**采用** Create 与 Destroy 严格配对，Stop/Release/异常路径均执行销毁
- **禁止** AudioCapturer 创建后不配对 Stop/Release，**采用**封装类析构时 Stop + Release，确保音频设备释放
- **禁止**回调指针无锁保护跨线程访问，**采用**读写锁保护回调指针的读写
- **禁止** SurfaceBuffer Acquire 后不 Release，**采用** Acquire 与 Release 严格配对，防止缓冲队列积压
- **禁止**监听器注册后不注销，**采用**按位图注册与统一注销配对，Server 释放时注销全部
- **禁止**通知栏发布后不移除，**采用**录屏开始发布、结束/异常时移除，通知 ID 生命周期与录屏会话一致
- **禁止**音频缓冲无限积压，**采用**预分配 + 容量上限，满时丢弃旧帧
- **禁止**超限创建录屏实例（超全局上限或单 UID 上限），**采用**创建前检查计数
- **禁止**裸指针跨模块传递，**采用** unique_ptr（唯一所有权）或 shared_ptr + weak_ptr（共享所有权打破循环）
- **禁止** C 风格强制类型转换，**采用** static_cast / dynamic_cast / reinterpret_cast 并注明理由
- **禁止**公共头文件与内部实现混放，**采用** InnerAPI 头文件放 interfaces/inner_api/，与 services/ 和 frameworks/ 严格分离
- **禁止**多线程访问共享状态不加锁，**采用**互斥锁或原子变量保护
- **禁止**持锁状态下调用外部模块未知接口，**采用**锁内只操作本模块数据，跨模块调用释放锁后执行
- **禁止**回调线程/IPC OnRemoteRequest 执行耗时阻塞操作，**采用**异步投递
- **禁止** IPC 回调链路同步等待客户端响应，**采用**异步投递

## 其它编码铁律

> 描述安全、内存、性能等编码规范要求

- **禁止**公开 API 跳过权限校验，**采用**所有入口执行权限验证，系统敏感接口校验调用者身份
- **禁止** IPC 反序列化跳过参数校验，**采用**校验必要字段存在性 + 取值范围合法性（CaptureMode/DataType 等枚举边界）
- **禁止**虚拟屏幕 screenId 未校验直接使用，**采用**创建返回值校验，无效 ID 返回错误
- **禁止**音频采集 sourceType 非法值直接传入，**采用**枚举边界校验（SOURCE_INVALID 拒绝）
- **禁止**隐私窗口保护遗漏系统级或应用级，**采用**同时设置 systemPrivacyProtection 和 appPrivacyProtection
- **禁止** SurfaceBuffer 跨 IPC 传递裸指针，**采用**Surface/BufferStack 序列化或文件描述符传递
- **禁止**音频混音热路径分配堆内存，**采用**预分配缓冲，严禁每帧 new/malloc
- **禁止**视频帧路径冗余数据拷贝，**采用**SurfaceBuffer 引用传递零拷贝
- **禁止** Stop 操作阻塞 UI 线程，**采用**异步执行 + 资源释放
- **禁止**虚拟屏幕/AudioCapturer 等系统资源不释放，**采用**录屏销毁时统一销毁虚拟屏幕、停止采集器、注销死亡通知
- **禁止** GN 构建遗漏 CFI 安全编译标志，**采用**共享库启用 CFI 强化
- **禁止**通话中断策略硬编码，**采用**策略结构体可配置
- **禁止** Picker 用户选择结果未经校验直接应用，**采用**上报后校验合法性再配置录屏目标

## Agent 常见失败模式

> 记录 Agent 在本项目中高频出现的错误模式，编码时务必规避

| # | 失败模式 | 违反铁律 | 正确做法 |
|---|---------|---------|---------|
| 1 | 在操作入口跳过能力位图校验直接执行 | 通用-3 | 每个操作入口先校验当前状态能力，非法状态返回 MSERR_INVALID_OPERATION |
| 2 | 新增状态但未更新状态-能力映射数组 | 通用-3 | 新增状态枚举值时同步扩展映射数组，确保元素对齐 |
| 3 | 虚拟屏幕创建后异常路径未销毁 | 通用-5 | 所有创建路径配对销毁，包括 Init 失败、Start 失败、Stop、Release |
| 4 | 跨 IPC 边界传递裸指针或引用 | 通用-1 | 通过 MessageParcel 序列化 |
| 5 | 为录屏引入独立引擎层/Pipeline | 通用-2 | 直接调用系统能力（通过依赖注入） |
| 6 | 跳过权限校验或隐私授权直接开始录屏 | 通用-4 | Start 前校验权限，走授权弹窗流程 |
| 7 | 新增系统监听器但未通过统一管理器注册 | 通用-9 | 通过位图注册，Server 释放时统一注销 |
| 8 | Acquire Buffer 后未调用对应 Release | 通用-8 | 严格配对，防止队列积压 |
| 9 | 回调指针跨线程读写未加锁 | 通用-7 | 使用读写锁保护回调指针的读写 |
| 10 | 超限创建录屏实例 | 通用-12 | 创建前检查全局/单 UID 计数 |
| 11 | 通知栏发布后未在 Stop/Release 时移除 | 通用-10 | 录屏开始发布，Stop/Release/异常路径均移除 |
| 12 | 新增枚举值但未校验边界 | 其它-2 | 校验 MIN/MAX 边界，非法值返回错误 |
